# Green Credit Data Scraping and Processing Workflow

The Green Credit data processing workflow consists of three Python scripts. These scripts handle state-wise data scraping, merging state-level GeoJSON files, and comparing datasets to remove duplicate records and generate the final updated Pan-India dataset.

## 1. `green_credit/scrape_green_credits.py`

**Purpose:** Scrape Green Credit data state-wise.

- Maintains the list of states for which data needs to be scraped (line number approximately **1200**).
- Scrapes the Green Credit data for the specified states.
- Generates output in both **CSV** and **GeoJSON** formats.
- All state-level GeoJSON files are saved in:

  ```text
  green_credit/ALL_STATE_GEOJSON/
  ```

**Output:**
- State-wise CSV files.
- State-wise GeoJSON files.

## 2. `green_credit/merge_geojson.py`

**Purpose:** Merge all state-level GeoJSON files into a single Pan-India GeoJSON file.

- Reads all GeoJSON files generated by `scrape_green_credits.py` from `green_credit/ALL_STATE_GEOJSON/`.
- Merges the state-level GeoJSON data into one consolidated dataset.

**Output:**

```text
PAN_INDIA_merged.geojson
```

## 3. `Compare_geom.py`

**Purpose:** Compare the previously scraped dataset with the current dataset, identify and remove duplicate records, and generate the final updated dataset.

- Compares the last scraped data with the current scraped data.
- Identifies duplicate geometries/records.
- Removes duplicate records.
- Retains the updated dataset after comparison.

**Output:**

```text
PAN_INDIA_updated.geojson
```

---

## Overall Workflow

Execute the scripts in the following order:

```text
1. scrape_green_credits.py
          |
          v
2. merge_geojson.py
          |
          v
3. Compare_geom.py
          |
          v
   PAN_INDIA_updated.geojson
```

| Step | Python Script | Description | Output |
|---|---|---|---|
| 1 | `scrape_green_credits.py` | Scrapes state-wise Green Credit data | CSV and state-wise GeoJSON files |
| 2 | `merge_geojson.py` | Merges all state-level GeoJSON files | `PAN_INDIA_merged.geojson` |
| 3 | `Compare_geom.py` | Compares datasets and removes duplicates | `PAN_INDIA_updated.geojson` |

**Final Output:** `PAN_INDIA_updated.geojson` — the consolidated, deduplicated, and updated Pan-India Green Credit dataset.
